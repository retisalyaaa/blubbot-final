# 🐟 BlubBot — Asisten Pintar Perawatan Ikan Hias

**BlubBot** adalah aplikasi chatbot berbasis web yang dirancang untuk membantu pengguna mendapatkan informasi seputar perawatan ikan hias. Chatbot ini menyediakan informasi mengenai pakan, kualitas air, suhu akuarium, dan berbagai tips perawatan ikan melalui interaksi yang sederhana dan interaktif.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| Python | Bahasa pemrograman utama |
| Flask | Framework aplikasi web |
| SQLite | Database |
| HTML & CSS | Antarmuka pengguna |
| JavaScript | Interaksi halaman web |
| JSON | Penyimpanan data dan konfigurasi |
| Pytest | Pengujian aplikasi |

## 🚀 Instalasi dan Menjalankan Project

**1. Clone repository**

```bash
git clone https://github.com/retisalyaaa/blubbot-final.git
```

**2. Masuk ke direktori project**

```bash
cd blubbot-final
```

**3. Buat dan aktifkan virtual environment**

```bash
python -m venv venv
```

Windows:
```bash
venv\Scripts\activate
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Jalankan aplikasi**

```bash
python app.py
```

Buka browser dan akses:

```text
http://127.0.0.1:5000
```
